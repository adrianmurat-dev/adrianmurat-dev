##  Engineering Principles

1. **Simple over clever.** Readable code that the next engineer can change safely.
2. **Design for failure.** Retries, idempotency, timeouts, and graceful degradation by default.
3. **Measure first.** Profile and instrument before optimizing.
4. **Data you can trust.** Validation at the boundaries, lineage you can trace.
5. **Automate the boring parts.** Tests, deploys, and checks belong in CI.
